| File | Where it goes |
|---|---|
| `.assistant/skills/<skill>/SKILL.md` | `./upload.sh user` → `/Users/<you>/.assistant/skills/`, or `./upload.sh workspace` → `Workspace/.assistant/skills/` (shared, admins) |
| `AGENTS.md` | Root of the Git folder (repo) Genie Code works in — Genie Code auto-discovers `AGENTS.md`/`CLAUDE.md` |

What's different from the repo setup:
- **Team skills are left out** (`orchestrate-team`, `worker-protocol`, `merge-train`): Genie Code is a single agent with no subagents, git worktrees, or hooks. Run agent teams from Claude Code or Codex via `ug` instead.
- **`make` targets are translated**: skills that mention `make` include a table of notebook / job equivalents.
- **Guardrails** come from Unity Catalog and job permissions plus the "Needs human approval" list in `AGENTS.md`.

Edits to skills apply in a new Genie Code chat; hard-refresh the browser if a skill looks stale. Invoke a skill explicitly with `@<skill-name>`.
