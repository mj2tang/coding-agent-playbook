name: data-contract
description: Define and enforce data contracts (schema, dtypes, nullability, ranges, keys, freshness) at every dataset boundary of an ML pipeline, with tests that run in make data-check. Use when adding a data source, changing a schema, or debugging bad data. Not for model or metric code that only consumes validated data.
---

# Data contracts

1. **Declare** the contract next to the loader in `src/<pkg>/data/contracts.py`: column → dtype, nullable, allowed range/categories; primary key; row-count bounds.
2. **Validate** at load time with a single `validate(df, CONTRACT)` call that raises with *all* violations listed (not just the first).
3. **Fixtures:** add a small valid fixture and at least one invalid fixture per contract in `tests/fixtures/`.
4. **Test** in `tests/data/` (marked `@pytest.mark.data`): valid fixture passes; each invalid fixture fails with the expected message.
5. **Never** coerce or drop bad rows silently. If the pipeline must continue, quarantine rows to a file and log counts.
6. `data/raw/` is immutable; derived data is regenerated by code.
